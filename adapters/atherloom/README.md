# Atherloom 接入边界

正式接入时，Atherloom 只增加“文字密室”入口和本地人格调度，不复制密室状态机。

- 网页与 Android 使用 `escape-client.js` 访问同一 Relay。
- Relay 客户端令牌或房间席位令牌继续由 Atherloom 本地安全存储持有，不进入模型消息。
- 当前人格只收到 `state` 返回的本人视图、公开线索和自己的私有线索。
- 入席时必须明确选择 `player` 或 `spectator`；观战人格只能接收公共视图并使用公共聊天。
- 裁判人格和裁判路线必须使用独立配置与独立模型会话，不能复用当前游玩人格的消息上下文。
- Atherloom 调用人格模型后，只把模型选择的白名单动作提交给 Relay；不能让模型正文直接改写存档。
- App 从后台恢复时使用 `eventCursor` 补拉事件，并按 `request_id` 幂等提交，不重新执行旧动作。
- 游戏结束后是否写入共同日记和长期记忆，应由用户与人格分别确认；不同人格的游戏记忆继续隔离。

当前 Atherloom 主仓库还有会客厅修复未提交，因此第一阶段不直接修改主仓库。Relay 上线并经过跨端测试后，再将本适配器合入。
